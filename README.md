# OSDU Azure SPI Fieldnotes: media

Video files for the Fieldnotes on the [OSDU Azure SPI training site](https://danielscholl-osdu.github.io/osdu-spi-training/), served from GitHub Pages so the site's repository stays small. Each `fieldnote-NN/` folder holds one episode: `video.mp4`, `poster.jpg`, `captions.vtt`, and `chapters.vtt`.

The scripts and storyboards live in the training repository under `docs/fieldnotes/`. A file here is replaced only by a re-cut from an approved storyboard.
